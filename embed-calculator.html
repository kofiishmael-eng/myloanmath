Frequently asked questions

Is embedding free?

Yes, for any site. There is no registration, no key, and no limit on page views. The only condition is that the credit line included in the embed code stays visible.

Do the embeds contain ads or tracking?

No. Advertising and analytics are stripped from every embed, so nothing loads inside your page except the calculator itself. Calculations run in the visitor’s browser and nothing they enter is transmitted anywhere.

Will the calculator resize itself?

Only if you add the optional snippet above. Without it the iframe keeps the fixed height you chose, which is pre-filled with a value that fits the tool.

Can I change the styling?

Not from your side, since the frame is served from myloanmath.com. You can set any width and height. If a specific variation would be useful, ask via the contact page.
